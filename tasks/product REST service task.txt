manager
	- ManagerContract<T,TPKey>
		- add(T p) => T
		- delete(TPKey id) => T
		- update(TPKey id, T p) => T
		- fetchAll() => List<T>
		- fetch(TPKey id) => T
		- search(String name) => List<T>

	- ProductManager -> ManagerContract<Product,Integer>
		- add(Product p) => Product
		- delete(Integer id) => Product
		- update(Integer id, Product p) => Product
		- fetchAll() => List<Product>
		- fetch(int Integer) => Product
		- search(String name) => List<Product>

		private helper methods
		- autogenerateId():Integer
		- sort():List<Product>
					

repository (data access layer/persistence layer)
	- RepositoryContract<T,TPKey>
		- insert(T p) => T
		- remove(TPKey id) => T
		- modify(TPKey id, T p) => T
		- getAll() => List<T>
		- get(TPKey id) => T

	- ProductRepository -> RepositoryContract<Product,Integer>
		- insert(Product p) => Product
		- remove(Integer id) => Product
		- modify(Integer id, Product p) => Product
		- getAll() => List<Product>
		- get(int Integer) => Product
