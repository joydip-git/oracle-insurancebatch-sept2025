create a Java application which calculates area of different shapes

there are many types of shape, but for our application use two types of shapes:
Circle:
	attributes: radius of the circle
	functionality: create a method in the class which calculates the area of the circle and returns the calculated area

Triangle:
	attributes: base of triangle, height of triangle
	functionality: create a method in the class which calculates the area of the triangle and returns the calculated area

in the Java application:
1. create classes for those two types
2. they must have necessary default and parameterized constructors, data members, getter/setters and methods

Hint: create also a base class (concrete/abstract)/interface as you feel necessary

3. in main method create objects of these two types
	a. print menu for user so that user can choose which type of shape object to be created
	b. based on the choice you create that type of object	
	d. calculate the area of the shape by calling the method and print the return value
