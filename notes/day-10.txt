ResourceConfig:
--------------------------
ResourceConfig is a core class in the Jersey framework, which is the reference implementation for JAX-RS (Java API for RESTful Web Services). 
It extends the JAX-RS "Application" class and provides enhanced capabilities for 
	- configuring and deploying Jersey applications.

Key functions and features of ResourceConfig:

Component Registration: It simplifies the registration of JAX-RS components, including:
Root resource classes: Classes annotated with @Path that define the entry points for your RESTful services.

Provider classes: Classes implementing JAX-RS or Jersey contract providers (e.g., MessageBodyReader, MessageBodyWriter, ExceptionMapper).

Features: Classes implementing Feature to add custom functionality or configuration to your Jersey application.

Binders: Classes implementing Binder for dependency injection.

Scanning capabilities: 
ResourceConfig offers advanced mechanisms to automatically discover and register components:

Classpath scanning: It can scan specified packages or the entire classpath for root resource and provider classes.

Package scanning: You can specify a set of package names, and ResourceConfig will automatically find and register JAX-RS components within those packages.

Configuration: It allows for programmatic configuration of various aspects of your Jersey application, such as: Setting properties, Registering instances of components, Applying features.
