JavaScript Object Notation/XML 

Consumer -> the one who uses/consumes the service

Provider -> the one who provides a service

Consumer and Provider can exchange data in platform/technology neutral manner
such as via JSON or XML format etc.

Consumer will convert their technology/language specific data into JSON/XML format -> Serialization
Provider after receiving the request (via web server) and fetching that JSON/XML data, will convert it into its language specific format -> Deserialization

Consumer and Provider will communicate via similar protocol as decided by Provider
Consumer and Provider will communicate via a standard neutral data exchange format as decided by Provider
Provider will also decide on the security feature for request/response

Protocols:
	HTTP - stateless and connectionless, provide no security to the data
	TCP - stateful and connection full, provide security to the data
