Step-1: compilation (static)
-----------------------------
App.java (source code) -> compiler (javac) -> App.class (byte-code - a type of intermediate language code)
Platform neutral code that is portable to and executable in any machine.

Step-2: (run)
----------------
use java.exe which provides the runtime environment.
App.class -> Just-In-Time compiler (part of runtime) -> machine language/level code (executable) -> execution begins from "main" method.

JIT will first convert the main method byte code to executable code ONLY and then begin execution from main method.

now, if during execution the runtime finds out/comes across another method that you are calling, then that method code will be JIT compiled (byte code will be converted to machine language code). if you even call the same method repeatedly, the same method will NOT be JIT compiled repeatedly.
This improves the performance of the application, as the application's entire byte code is NOT converted to machine language code at one go.

PrintStream: 
	- The "standard" output stream.
	- This stream is already open and ready to accept output data.
        - Typically this stream corresponds to display output or another output destination specified by the host environment or user.
        - The encoding used in the conversion from characters to bytes is equivalent to "stdout.encoding"
        PrintStream ps = System.out;

naming convention:
-----------------------
method name: 
	- camel casing (first letter of first word in lower case but first letter of subsequent words in upper case in multi-word name)
	- should sound like "verb"

ex: doSomething()

variable name: 
	- lowercase or camel case 
	ex: mydata/myData
	- no digits, special character
	- like noun



best practices:
------------------------
always use separate methods/classes to do exactly one job
	- increases modularity
	- increase readability
	- increase reusability
	- helps you to debug code easily
