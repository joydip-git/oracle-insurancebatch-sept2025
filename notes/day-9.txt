RESTful API:
-----------------------
	classes with methods
	the methods are callable/invocable via web (can be requested via method, such as GET, POST, PUT, PATCH, DELETE, OPTIONS etc. of HTTP protocol)
	the methods can return different type of data in different format, such as, XML, JSON etc.

	the methods MUST be annotated with either of the following annotations:
	@GET, @POST, @PUT, @DELETE, @PATCH etc. to indicate which method of HTTP protocol should be used to request that method
	the method optionally will have an URI
	the method must mention what type of data it is returning
	optionally the method can mention what type of data it is consuming
	you can set a base path for all methods of a class one time at the tope of the class
	
	@Path("dataresource")
	public class DataService{

		@GET
		@Path("welcome/{fname}/{lname}") //name -> path parameter
		//@Produces("text/plain")
		@Produces(MediaType.TEXT_PLAIN)
		public String getName(@PathParam("fname") String fName, @PathParam("lame") String lName){
			return " welcome "+fName+" "+lName;
		}

		@GET
		@Path("hi")
		//@Produces("text/plain")
		@Produces(MediaType.TEXT_PLAIN)
		public String get(@QueryParam("name") String fName,@QueryParam("lname") String lName){
			return " hi "+fName+" "+lName;

		}

		@POST
		@Path("add") 
		@Consumes(MediaType.APPLICATION_JSON)
		//@Produces(MediaType.TEXT_PLAIN)
		@Produces(MediaType.APPLICATION_JSON)
		public Person addPerson(Person person){
			return person;
		}	
	}

	public class Person{
		private String name;
		private int id;
	}

Resource instance Lifecycle:
-----------------------------------
Servlet creating instance of MyResource and placing it inside a container
every time new request comes an instance of MyResource is created and once the response is returned the instance is destroyed

MyResource instance is scoped to a request

Singleton: an instance of a Resource class is created ONLY once and destroyed when the application is stopped or the server stopped

Session Scoped: For a certain duration an instance will be created and kept alive for a particular client

Request Scoped: Every time a new instance of a Resource type is created for every request
The RESTful API Resource classes are by default RequestScoped
Note: That's why it is not a good practice to maintain state of any data inside the resource class

Note: since RESTful APIs generally should not maintain as such any session with the client, hence session scoped instance is not preferred, until and unless you want to have session with the client.
 

Generating HTTP response using Response type
--------------------------------------------------
ResponseBuilder builder = Response.ok()/.createdAt()/.badRequest()/.notModified()
Response resp = builder.build();
or
Response.status(200).entity(data).build();

create a RESTful application with methods that can be requested via HTTP protocol's GET, POST, PUT, DELETE methods 
using @GET, @POST, @PUT, @DELETE annotations with methods
using @QueryParam and @PathParam annotation with method parameters
using @Path annotation with Resource class and its API methods
using @Produces and @Consumes annotation with API methods
