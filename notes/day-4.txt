Utility class:
	such a class where every member is static, starting from data members, constructors, getter/setters and methods. This type of class generally does not contain instance data.
We do not create instance of such class. The idea is to create such a class whose members will be used so frequently that we do not want to create instance of it.

class Utility{
	private static Scanner scanner;
	//this static block code is executed ONLY once and very first time you use this class
	static {
		scanner = new Scanner(System.in);
	}
	public static printMenu(){}
	public int static getChoice(){ return 0;}
	public static void dispose(){
		scanner.close();
	}
	
}

Utility.printMenu();
Utility.getChoice();
Utility.dispose();

Comparison of values in Java:
--------------------------------
A. Internalization: comparison logic is written inside the model/entity (T) by implementing Comparable<T> interface from java.lang package

Comaparable<T> =>  public int compareTo(T o);

class Integer implements Comaparable<Integer>, Comparator<Integer>{
	 public int compareTo(Integer o){
		return this.intValue() - o.intValue();
	 }
	 public static int compare(Integer o1, Integer o2){
		return o1.intValue() - o2.intValue();
	 }
}

Comaparator<T> => int compare(T o1, T o2);

Set:
---------------
It is a collection of unique items, .i.e., no duplicate items can be added in this collection
Set collection types do not provide indexing facility, i.e. you can't fetch a value from Set using index position

when you add an element in Set<T> instance using add() method
	- add() method calls hashCode() method of the every T type item that you add in the collection
	- when you try to add the next element, add() method checks whether the hash code of this element (that you are adding) is by any chance same as that of the hash code any previous item
	- if the hash code of the current element that you are adding is same as that of the hash code of any previous element, then add() method calls equals() method of the T type item on the current element and passes the other item (whose hash code is same as that of the current element) as an argument to the equals() method
	- if the equals() method returns true, indicating that the current and the other element (whose hash code is same as that of the current element), are identical, then the current element will not be added in the Set
